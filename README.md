## Description
A fully responsive website for Golden Valley PNG Enterprise Limited, a licensed gold buyer and exporter based in Papua New Guinea.

## Technologies Used
- HTML5
- CSS3 (Flexbox + CSS Grid)
- Vanilla JavaScript
- Media Queries

## Responsive Design
- Mobile, tablet and desktop layouts
- Flexible units and media queries
- Structure changes across breakpoints (not just shrinking)
- Responsive navigation with hamburger menu

## How Flexbox and CSS Grid were used
- Flexbox: navigation, header, hero actions, footer, form layout
- CSS Grid: service cards, location sections, page layouts, contact section

## Testing
Tested on:
- Desktop (Chrome)
- Tablet view
- Mobile view

## AI Use Declaration
I used GitHub Copilot to assist with writing and refining HTML and CSS. All final design decisions, structure, and code were reviewed and controlled by me.
